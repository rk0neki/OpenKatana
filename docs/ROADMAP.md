# Development plan

Version 0.1.0 includes 72 shared MCP/CLI operations, local
Studio, timeline editing, audio, responsive compositions/plugins, advanced text,
WebGL and optional Blender authoring, HDR finishing and Comfy model workflows.

Current release priorities:

1. Validate installation and the portable agent setup on fresh environments.
2. Review Studio usability and actual output with human editors.
3. Exercise longer footage, varied frame rates/resolutions, occluded tracking,
   matte edges, multilingual typography and audio synchronization.
4. Expand optional-model and glTF-extension coverage with licensed fixtures.
5. Review dependency notices, release artifacts and CI results for each release.

See [capabilities](CAPABILITY-MATRIX.md), [known limits](CAPABILITY-GAPS.md) and
[validation](VALIDATION.md). New feature claims require tests of that behavior;
a successful small fixture does not establish universal support or quality.
