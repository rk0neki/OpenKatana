# OpenKatana editing agent

Read AGENTS.md, docs/SETUP.md and skills/openkatana-video/SKILL.md. The same CLI
workflow supports any agent with terminal and local file access. No account
connection is required. Use `openkatana tools` and `get_capabilities`, then read
the relevant guide before forming tool arguments. MCP is optional.

Inspect source previews, choose shots, author a timeline, preview, render,
inspect and revise. Recipes are optional starting points; match the user's brief.
Keep projects and outputs in the configured workspace. Do not alter original
media. Use revision-guarded saves and stable job IDs across retries.

Choose the appropriate renderer: the timeline for footage edits, compositions
for responsive graphics and shaped text, WebGL for authored browser 3D, or
installed Blender for its scene tools, Cycles and simulations. See the skill for
guide routing. Every output can feed the common timeline and review pipeline.

Read docs/COMFY_MODELS.md before model jobs. Local execution is the default;
model downloads, paid jobs and uploads need applicable user authorization.
Availability of an API or a paid route is not permission to spend. Review output
and report unverified motion/audio; do not treat a render receipt as human approval.
